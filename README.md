# Laptop Price Prediction

Пайплайн машинного обучения для прогнозирования цен на ноутбуки на основе технических характеристик.
* Feature Engineering: с помощью регулярных выражений извлекла из текстовых полей более 20 новых признаков: разрешение и тип экрана, производитель / модель / частота CPU, объём и тип дисков, вес и др.;
* Применила нечёткое сопоставление (thefuzz) для нормализации 46+ вариантов написания названий GPU NVIDIA к каноническому словарю;
* Обработал категориальные признаки: One-Hot для низкокардинальных, Target Encoding для высококардинальных (Company, Cpu_name, gpu_name).
* Подобрала гиперпараметры с помощью Optuna;
* Протестировала и сравнила 5+ моделей;

**Результат:** R² = 0,87 (градиентный бустинг) на контрольной выборке.

## Основные моменты
- Разбор неструктурированных текстовых полей (CPU, Memory, ScreenResolution) с помощью регулярных выражений.
- Нормализация 46+ вариантов названий графических процессоров с помощью нечеткого сопоставления.
- Создание 20+ числовых признаков на основе необработанных строк.
- Тестирование 5+ моделей; интерпретация драйверов с помощью SHAP.
