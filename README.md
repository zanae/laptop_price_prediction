# Laptop Price Prediction
Сквозной пайплайн машинного обучения для прогнозирования цен на ноутбуки на основе технических характеристик.

**Результат:** R² = 0,87 (градиентный бустинг) на контрольной выборке.

## Основные моменты
- Разбор неструктурированных текстовых полей (CPU, Memory, ScreenResolution) с помощью регулярных выражений.
- Нормализация 46+ вариантов названий графических процессоров с помощью нечеткого сопоставления.
- Создание 20+ числовых признаков на основе необработанных строк.
- Тестирование 5+ моделей; интерпретация драйверов с помощью SHAP.
